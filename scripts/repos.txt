# The bro ecosystem's repositories: the one machine-readable list.
#
# docs/ecosystem.md is the human index (a role and a description per repo);
# this file is what tooling reads (scripts/repo-status.sh, scripts/repo-status.ps1,
# tests/run_tests.sh). Add a repo here and to docs/ecosystem.md together.
#
# Every repo lives at github.com/wlejon/<name> and is checked out beside bro, at
# ../<name>. Columns are whitespace-separated; '-' means none.
#
#   name       repository name (and directory name under the projects root)
#   group      runtime | compiler | engine | terminal | desktop | app | tool
#                runtime   bro itself
#                compiler  bronze and brass, which run every app's JavaScript
#                engine    libraries bro links for its engine subsystems
#                terminal  libraries bro links for the <terminal> element
#                desktop   desktop-environment substrate libraries (bro mounts their JS bindings)
#                app       applications that run on, or link, bro
#                tool      development tools around bro
#   bro        self      | submodule (bro records it at third_party/<name>) | -
#   github     public | pending (not on GitHub yet)
#   platforms  comma-separated: win, linux, mac
#   deps       comma-separated bro-ecosystem repos it builds against (from its CMake)
#
