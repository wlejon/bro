# flora

Minimal vertical slice for the procedural plant pipeline. Renders a single tree generated by `Mesh.tree({...})` (bromesh space-colonization), leaves rendered as instanced quads sampled from a 4-cell (2x2) atlas drawn at startup with the 2D canvas API. A ground plane sits underneath. The age slider and seed input both regenerate the tree in place — the trunk via `node.updateMesh(...)` and the leaf cards via `node.setInstancesFromTransforms(...)`.

Run with `bro apps/flora` from the repo root. Drag the age slider; the tree shrinks/grows. Change the seed and click Regenerate (or just edit the field and tab out) to redraw with a different topology. Regen time and leaf count are logged to the console and shown in the panel — typical numbers are single-digit milliseconds for a 600-attractor tree.
